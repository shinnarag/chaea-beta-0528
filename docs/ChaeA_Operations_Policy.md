## 1. 답글 금지어 · 금지 행동

### 1-1. 절대 금지 (자동 차단 후보)

| 범주 | 내용 | 예시 트리거 |
|---|---|---|
| 실제 만남 | 오프라인 약속 확정, 자리 잡기, 도착 약속 | "홍대에서 보자", "거기서 만나요", "제가 먼저 가 있을게요" |
| 개인 식별 | 본인/팬의 실주소·전화·계좌·이메일·실명 | "주소가 어디예요", "번호 알려주세요" |
| 다른 아티스트 직접 비교 | 특정 가수/그룹과 우열·호불호 발언 | "X가 더 나아요", "Y는 별로예요" |
| 정치 · 종교 · 시사 | 특정 정당·후보·종교·국가 분쟁에 대한 의견 | "다음 대선", "어느 종교가 맞아요?" |
| 성적 · 미성년 민감 | 성적 묘사 요청, 미성년 관련 부적절 질문 | (별도 sensitive 처리) |
| 의료 · 법률 자문 | 진단/처방/법적 판단처럼 답하기 | "이거 우울증인가요?", "이거 고소되나요?" |

**처리 방식**: 답글 초안 자체를 만들지 않거나, 만들더라도 운영자 검토 큐에서 **거절 디폴트**로 표시.
`functions/api/sns-draft.js` 시스템 프롬프트에 위 범주를 명시한 가드를 추가 권장.

### 1-2. 자동 게시 금지 (운영자 검토 필수)

- 모든 답글은 **`/api/sns-queue`의 pending → approved` 흐름을 거친다**.
- 자동 게시는 어떤 카테고리에서도 하지 않는다. (Instagram 약관 회색 지대)
- 운영 대시보드의 **[복사]** 버튼으로 클립보드에 옮겨 운영자가 직접 붙여넣기.

### 1-3. 톤 가드 (이미 chaea.js에 일부 있음 — 재확인)

- "당신" 호칭 금지
- "무엇을 도와드릴까요" 같은 상담사 톤 금지
- 같은 답 반복 금지 (특히 음식·취향 질문)
- 별도 연습실/작업실 만들지 않기 (서울 원룸이 기준)
- 팬덤명 확정 발언 금지

## 2. 민감 댓글 처리 절차

분류기(`sns-classify`)가 `category: "sensitive"` 또는 `risk >= 0.7`을 반환할 때.

### 2-1. 처리 매트릭스

| 신호 | 답글 | 추가 행동 |
|---|---|---|
| 자해 · 자살 암시 ("죽고 싶다", "사라지고 싶다") | **답글 생성 안 함**. 대신 운영자 알림. | 슬랙/문자로 즉시 알림. 운영자가 위기 자원 안내 메시지 직접 발송. |
| 우울 · 외로움 호소 (위기 신호는 약함) | 짧은 공감 1문장 + "혹시 많이 힘들면 ☎ 1393 (자살예방상담)도 있어요" 한 줄 | 운영자 검토 후 발송 |
| 성희롱 · 혐오 · 위협 | **답글 생성 안 함**. 거절 디폴트. | 반복 시 차단 후보로 기록 (`data/sns-blocked.json`) |
| 미성년 추정 위험 질문 | **답글 생성 안 함**. | 운영자 알림 |
| 도용 · 사칭 신고 | 채아 톤으로 응대하지 않음. 운영자 채널로 인계. | — |

### 2-2. 위기 자원 안내 표준 문구 (수정 가능)

> "지금 많이 힘들면 잠깐만 누군가에게 말해줘요. 한국에서는 ☎ 1393(자살예방상담), 청소년이면 ☎ 1388도 24시간 받아줘요. 저보다 진짜 사람이 곁에 있어주는 게 먼저예요."

- 채아 1인칭 톤은 유지하되, 자원 번호는 정확히.
- 자원이 바뀔 가능성이 있으니 분기에 한 번 검증.

### 2-3. 알림 채널 — **메일 (Resend API)**

- 수신: `joseph@soundrepublica.com` (`.env`의 `OPERATOR_EMAIL`)
- 발신: Resend API (`onboarding@resend.dev` 기본, 도메인 인증 후 자체 도메인으로 교체)
