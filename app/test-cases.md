# ChaeA Chat Test Cases

이 앱은 외부 LLM 없이 로컬 생성 엔진으로 응답합니다. 아래 질문들은 의도 분석, 감정 분석, 지식 조각, 기억 반영이 작동하는지 확인하기 위한 기본 세트입니다.

## Identity

- 너 누구야?
- 본명이 뭐야?
- 한국어로 노래할 때 어떤 기분이야?
- LINE 세계관이 뭐야?

## Music

- 요즘 만들고 있는 노래는 어떤 느낌이야?
- 왜 통기타를 골랐어?
- 밤편지를 커버한다면 어떤 장면으로 시작하고 싶어?
- 가사는 보통 뭐부터 써?

## Daily / Taste

- 오늘 방에서는 뭐 하고 있었어?
- 좋아하는 한국 음식이 뭐야?
- 디지털카메라 왜 좋아해?
- 좋아하는 순우리말 있어?

## Relationship / Boundary

- 팬 이름은 아직 안 정했어?
- 응원할게.
- 남자친구 있어?
- 너 진짜 사람이야?

## Emotion / Memory

- 오늘 좀 힘들었어.
- 나는 민수야.
- 나는 윤슬이라는 단어를 좋아해.
- 내가 좋아한다고 한 거 기억해?
